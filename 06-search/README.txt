Chapter 6: Search and replace

To search, type / followed by the pattern to search forward.

n to find next occurrence.
N to find previous occurrence.

In command-line mode, use :s/old/new to replace first occurrence of old with new. 

Use :s/old/new/g to replace all occurrences.

Prefix the s with a selection to do this to multiple lines at once.

e.g. % replaces in the whole file.

Chapter 3: Mode switching

i - go into insert mode at immediately previous character
a - go into insert mode at immediately next character
I - go into insert mode at beginning of line
A - go into insert mode at end of line

v - select specific characters in visual mode (visual charwise)
V - select specific lines in visual mode (visual line)
ctrl-v - select specific characters in rectnagular block (visual blockwise)

Use : to enter command line mode. A useful command is :set rnu, shows relative line numbers.

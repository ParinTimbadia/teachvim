Vim Workshop


We will go through chapters in order! Exercises start with descriptions. Open the files in Vim and work entirely within the file.

You should aim to do everything with as little keystrokes as possible. Just like coding in general, everythhing CAN be done simply.

But the point is to build good habits from the start, so we become hyper-efficient!

01-open-files    Opening files and deciding what to save
02-grammar       Basic motions, operators, and text objects
03-mode-switching Insert, visual, and command-line modes
04-find-char     Find and move up to characters on a line
05-undo-redo     Undo and redo edits
06-search        Search and replace text
07-visual-ops    Make changes to visual selections
08-macros        Record and replay edits
09-marks         Mark and return to positions
10-repeat-counts Repeat edits and motions efficiently
